# Google Sign-In in Flutter with flutterfire_cli (Intermediate)

## Overview
Integrate Google Sign-In into a Flutter app, using `flutterfire_cli` for Firebase setup. This guide is for intermediate developers and focuses on the `google_sign_in` package.

## Prerequisites
- Flutter project with Firebase set up via `flutterfire_cli` (e.g., `flutterfire configure`).
- Firebase initialized for other features.

## Android Configuration
1. **SHA-1**:
   - Run `./gradlew signingReport` in `android/`, copy debug SHA-1.
   - Add to Android OAuth client ID.
   - **Important Note**: For production (e.g., when releasing to Google Play), also add the release SHA-1. To generate the release SHA-1, configure your release signing key in `android/app/build.gradle.kts` by adding the JKS path and passwords:
     - Create or use an existing JKS file (e.g., `my-app-key.jks`) with a key alias (e.g., `my-key-alias`).
     - Add to `android/app/build.gradle.kts` (updated to Kotlin DSL for Flutter 3.25+ compatibility):
       ```kotlin
       android {
           compileSdk = 34
           defaultConfig {
               applicationId = "com.example.myapp"
               minSdk = 21
               targetSdk = 34
               versionCode = 1
               versionName = "1.0"
           }
           signingConfigs {
               create("release") {
                   storeFile = file("/path/to/my-app-key.jks")
                   storePassword = "your-keystore-password"
                   keyAlias = "my-key-alias"
                   keyPassword = "your-key-password"
               }
           }
           buildTypes {
               getByName("release") {
                   signingConfig = signingConfigs.getByName("release")
                   isMinifyEnabled = true
                   proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")
               }
           }
       }
       ```
     - Then run `./gradlew signingReport` again and copy the SHA-1 from the "release" variant. Both debug and release SHA-1s must be added to the Google Cloud Console OAuth client ID for full app functionality.
2. **Gradle**:
   - **Optional**: If not already present, update `android/build.gradle` (typically handled by `flutterfire_cli`):
     ```groovy
     plugins {
         id 'com.google.gms.google-services' version '4.4.2' apply true
     }
     allprojects {
         repositories {
             google()
             mavenCentral()
         }
     }
     ```
     - Note: `flutterfire_cli` usually adds the `google-services` plugin and repositories when you run `flutterfire configure`. Skip this if already configured.
   - Add to `android/app/build.gradle.kts`:
     ```kotlin
     dependencies {
         implementation("com.google.android.gms:play-services-auth:21.2.0")
     }
     ```
   - Update `android/gradle/wrapper/gradle-wrapper.properties`:
     ```
     distributionUrl=https\://services.gradle.org/distributions/gradle-8.7-bin.zip
     ```
     - Note: This ensures compatibility with Flutter 3.25+; update manually if not already set.
   - `google-services.json` should be in `android/app` from `flutterfire_cli`.

## iOS Configuration
1. **Plist & Client ID**:
   - Verify `GoogleService-Info.plist` in `ios/Runner/` (from `flutterfire_cli`).
   - If missing, download from Firebase Console, add to `ios/Runner/`, run `pod install`.
2. **Info.plist**:
   - Add:
     ```xml
     <key>CFBundleURLTypes</key>
     <array>
         <dict>
             <key>CFBundleTypeRole</key>
             <string>Editor</string>
             <key>CFBundleURLSchemes</key>
             <array>
                 <!-- TODO Replace this value: -->
                 <!-- Use REVERSED_CLIENT_ID from GoogleService-Info.plist if present; otherwise, use CLIENT_ID prefixed with com.googleusercontent.apps. -->
                 <string>com.googleusercontent.apps.YOUR_IOS_CLIENT_ID</string>
             </array>
         </dict>
     </array>
     <key>GIDClientID</key>
     <!-- TODO Replace this value: -->
     <!-- Copied from GoogleService-Info.plist key CLIENT_ID -->
     <string>[YOUR IOS CLIENT ID]</string>
     ```
   - To find the keys: Open `GoogleService-Info.plist` in `ios/Runner/` (a text file generated by `flutterfire_cli`). Locate the `REVERSED_CLIENT_ID` key (e.g., `com.googleusercontent.apps.12345-abcde`) if it exists, or use the `CLIENT_ID` key (e.g., `12345-abcde.apps.googleusercontent.com`). For `CFBundleURLTypes`, use `REVERSED_CLIENT_ID` directly or prefix `CLIENT_ID` with `com.googleusercontent.apps.`. For `GIDClientID`, use `CLIENT_ID` as is.

## Flutter Implementation
1. **Dependency**:
   - In `pubspec.yaml`:
     ```yaml
     dependencies:
         google_sign_in: ^6.0.2
     ```
   - Run `flutter pub get`.
2. **Dart Code**:
   ```dart
   import 'package:flutter/foundation.dart';
   import 'package:google_sign_in/google_sign_in.dart';

   class GoogleSignInService {
     final GoogleSignIn _googleSignIn = GoogleSignIn(
       scopes: ['email', 'profile'],
       clientId: kIsWeb || defaultTargetPlatform == TargetPlatform.android
           ? null
           : 'YOUR_IOS_CLIENT_ID.apps.googleusercontent.com',
     );

     Future<Map<String, String?>> signIn() async {
       try {
         final account = await _googleSignIn.signIn();
         if (account == null) return {'error': 'Sign-in cancelled'};
         final auth = await account.authentication;
         return {
           'accessToken': auth.accessToken,
           'idToken': auth.idToken,
           'email': account.email,
         };
       } catch (e) {
         return {'error': e.toString()};
       }
     }

     Future<void> signOut() async => await _googleSignIn.signOut();
   }
   ```

## Usage
- Call `GoogleSignInService().signIn()` to authenticate.
- Handle returned `accessToken`, `idToken`, or `email`.

## Verification
- **Android**: Test on device, check SHA-1 and `google-services.json`.
- **iOS**: Run on simulator, verify plist and pods.
- Log `result['email']` to confirm.

## Troubleshooting
- **Android**: Ensure SHA-1 matches, `google-services.json` present.
- **iOS**: Check plist, re-run `pod install`.
- **General**: Update `google_sign_in` (^6.0.2+), review logs.

## Notes
- `flutterfire_cli` simplifies Firebase config; focus on Google Sign-In setup.
- Use tokens for custom backend integration.
